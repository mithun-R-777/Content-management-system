# Content-management-system

## Overview

The CMS-Backend project is a backend application for a Content Management System (CMS) built using Spring Boot. This project provides RESTful APIs for managing content data, including CRUD (Create, Read, Update, Delete) operations. It integrates with Spring Security for authentication and authorization, ensuring secure access to the system. The backend connects to a relational database for data storage, making it a robust solution for managing content information efficiently.

## Features

-RESTful APIs for content management

-CRUD operations for content data

-Authentication and authorization with Spring Security

-Integration with a relational database

-Efficient content management

## Technologies Used

-Java

-Spring Boot

-Spring Security

-RESTful APIs

-Relational Database

## Getting Started

Prerequisites

-Java Development Kit (JDK) 8 or higher

-Maven

-A relational database 

## Installation
Clone the repository:
git clone https://github.com/mithun-R-777/CMS-Backend.git
Navigate to the project directory:
cd CMS-Backend
Build the project using Maven:
mvn clean install

## Usage

-Access the API documentation at http://localhost:8080/swagger-ui.html (if Swagger is integrated).
-Use the provided RESTful APIs to manage content data.
